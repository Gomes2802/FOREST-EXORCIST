./start.sh

ou python3 serve.py. Não é necessária conexão com a internet.

CONFIGURAÇÕES

A qualidade também escolhe a resolução; depois é possível trocá-la. Na Automática, o jogo baixa a qualidade sozinho se ficar lento e avisa.
200% só tem efeito em imagens maiores que o tamanho padrão no jogo.
Os ajustes valem até a página ser fechada.

SAIR

O navegador não permite que o jogo feche esta aba sozinho.

Para sair, pressione Ctrl + W.

Se usou o terminal para abrir o jogo, pressione Ctrl + C nele.
